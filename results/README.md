# §5 Case Studies — results map

Generated by `scripts/make_readme.py`. Every figure follows the §0.5 convention `fig_{section}_{dataset}_{method}_{variant}.png`; all scalar indices live in `results_indices.csv`.

## Hyperparameters & seeds (§0.5)

- `random_state` / SEED = **0** (everywhere)
- embedding dim q = **2**
- kNN neighbours (graph methods / UMAP) k = **15**
- t-SNE perplexity / adaptive-Gaussian = **30**
- diffusion time t = **10.0**
- RV gradient ascent: **500** iters, Adam lr = **0.1**
- index neighbourhood k (trustworthiness / kNN overlap) = **15**
- init: framework uses full-scale PCA; sklearn t-SNE / UMAP references use the PCA init scaled to PC1 std 1e-4 (§0.2). Both share PCA directions, so Procrustes/RV comparisons stay legitimate.

## Datasets (§0.1)

- **singlecell** — 10x PBMC3k (scanpy-processed, PCA→50, cell-type labels)
- **mnist** — MNIST 2000 balanced (raw 784 pixels, digit labels)
- **swissroll** — Swiss-roll 2000 (raw 3D, continuous roll angle)

## results_indices.csv

Tidy long format, one row per index value. Columns: `section, dataset, method, variant, init, index_name, k, value, run_id`.

Key `index_name` values:
- `procrustes`, `knn_overlap` — identity (framework vs reference)
- `trustworthiness`, `ari` — quality (per variant)
- `rv_final` — final RV coefficient of the framework optimisation
